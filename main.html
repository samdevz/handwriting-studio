# Heading · ## Subheading · - bullet · Q1. … (5 marks) keeps room for the answer (or moves to the next page) · --- new page · blank lines stay blank.

If fewer lines than this are left, the question starts on the next page and the rest of the page stays blank. Marks like “(10 marks)” raise the requirement automatically.

Single pages can also be saved with the PNG / JPG buttons above each page. A one-page PNG or JPG export downloads as a plain image, not a ZIP.

Tip: click any line on a page to edit it right there. In Grid view, click a page to open it.
